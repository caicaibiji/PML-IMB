# PML-IMB 实验数据集

本仓库说明作者在 PML-IMB 论文实验中使用的 20 个部分多标签学习（partial multi-label learning，PML）数据集文件。其中，14 个文件是在已有多标签数据集基础上构建的合成 PML 版本；另外 6 个是从第三方研究资源下载的真实世界 PML 基准数据集。文件包含特征、真实标签和候选标签，并非新采集的原始数据。

下表记录的是为本次发布逐一检查的本地 `.mat` 文件，统计数字直接由文件计算，而非照抄论文表格。发布 Release 时，应确保附件中的文件名与下表完全一致。论文讨论的 20 个少数类标签评估子集，是在评估过程中从这 20 个数据集计算得到的；它们不是另一组需要上传的 20 个 `.mat` 输入文件。

## 数据来源与处理

**合成 PML 数据集（14 个文件）。** 论文指出，基础多标签数据来自[科尔多瓦大学 KDIS 多标签数据集资源库](https://www.uco.es/kdis/mllresources/)。为构造 PML 实验数据，在真实标签集合中随机加入假阳性标签，形成候选标签矩阵。文件名中的 `_50`、`_100` 或 `_150` 表示名义噪声设置，即相对于每个样本真实标签数量的百分比。论文还记载，预处理时剔除了候选标签全部为零的样本。目前未在这些文件的附带材料中找到原始数据生成脚本或随机种子，因此发布的 `.mat` 文件本身定义了实验所使用的精确版本。

**真实世界 PML 数据集（6 个文件）。** `mirflickr`、`music_emotion`、`music_style`、`YeastBP`、`YeastCC` 和 `YeastMF` 是从第三方下载的 PML 基准数据。论文将[东南大学 PALM 研究组的数据资源页](https://palm.seu.edu.cn/zhangml/Resources.htm)列为其来源。这些文件的候选标签不是本项目新生成的。本地三个 Yeast 文件分别包含 4,257、2,434 和 2,594 个样本；引用或使用时应指明这些确切版本，不能假定同名基准数据的样本完全相同。

KDIS 和 PALM 网页是数据来源说明，并非授予本仓库维护者重新分发第三方材料的许可。公开发布 `.mat` 文件时，必须遵守来源方适用的使用条款并取得所需权限。如果某个文件不能重新分发，应从原始来源获取，并说明如何得到实验所用的版本。

## 文件格式

每个 MATLAB `.mat` 文件包含以下变量：

| 变量 | 形状 | 含义 |
| --- | --- | --- |
| `data` | `N × d` | 特征矩阵，每行对应一个样本。 |
| `target` | `q × N` | 真实标签的二值矩阵。 |
| `candidate_labels` | `q × N` | 候选标签的二值矩阵，包含真实标签，也可能包含假阳性标签。 |

在 Python 中，将 `target` 和 `candidate_labels` 转置即可得到 `N × q` 矩阵。实验数据加载器使用候选标签训练，使用真实标签验证和测试。特征标准化器在每次划分的训练集上拟合，再应用于相应的验证集和测试集。

```python
from scipy.io import loadmat

mat = loadmat("datasets/Scene_50.mat")
X = mat["data"]
Y_true = mat["target"].T
Y_candidate = mat["candidate_labels"].T
print(X.shape, Y_true.shape, Y_candidate.shape)
```

## 下载与使用

在遵守原始数据提供方再分发条款的前提下，从 `dataset-v1.0` 版本的附件中下载 `.mat` 文件，并将它们放在同一个 `datasets/` 目录。**GitHub 自动生成的“Source code”压缩包并不是数据集压缩包。**运行配套的 PML-IMB 代码时，明确指定数据目录：

```bash
python main_graph_split_imb_val.py --data-dir /path/to/datasets
```

实验代码的默认数据集列表是上表 20 个文件名去掉 `.mat` 后缀的结果。若只运行部分数据集，可使用 `--datasets` 参数，例如：

```bash
python main_graph_split_imb_val.py --data-dir /path/to/datasets --datasets Scene_50,Water-quality_50,CAL500_150
```

论文报告了十折评估。少数类标签的结果，是在每次数据划分中根据训练集候选标签矩阵识别少数类标签后得到的；不需要另行准备 `_imb.mat` 文件。

## 引用与数据权利

使用这些文件时，请引用 PML-IMB 相关论文，以及适用的原始数据集论文或数据源。基础多标签数据集归属[科尔多瓦大学 KDIS 资源库](https://www.uco.es/kdis/mllresources/)所列来源；6 个真实世界 PML 基准数据见[东南大学 PALM 资源页](https://palm.seu.edu.cn/zhangml/Resources.htm)。特别地，`mirflickr.mat` 是用于 PML 的基准数据表示，并非完整的 [MIRFLICKR-25K 图像集合](https://press.liacs.nl/mirflickr/)。
